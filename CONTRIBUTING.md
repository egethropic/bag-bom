# Contributing

Issues and pull requests are welcome. Report the OS, KiCad version,
InteractiveHtmlBom version, browser, and steps to reproduce. If sharing a label
image or BOM, remove personal information, order details, and proprietary design
data first. A tiny synthetic reproducer is usually enough.

Run the tests and build in README.md before submitting code. Matching changes
must demonstrate that near misses, conflicting identities, and wrong packaging
suffixes do not become automatic selections. Include tests for camera or worker
lifecycle changes. Keep barcode decoding and OCR local and preserve the original board/export files.

Contributions are provided under Apache-2.0, the project's license.
